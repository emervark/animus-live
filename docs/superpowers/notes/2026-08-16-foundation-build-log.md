## Rulings

**R0: No worktree; use branch `feat/foundation-m0-core`.** — The `EnterWorktree` tool's contract restricts it to explicit user "worktree" requests, and it branches from `origin/<default>`, which does not exist in this fresh repo. There is no concurrent work, so a branch gives adequate isolation. — Cost if wrong: `git switch main` recovers; nothing is lost.

**R1 (F1): Add `serde_json.workspace = true` to `animus-core` `[dependencies]`.** — `Project.bindings` and the migration chain use `serde_json::Value` in non-test code; dev-dependencies would not compile. — Cost if wrong: none; it is a required dependency either way.

**R2 (F2): Pin `glam = "0.32"` in Task 1 directly; drop Task 2 Step 8's correction as a blocker.** — Probed `bevy =0.19.1` and it resolves `glam v0.32.1`. Determining this now removes T6–T14's hidden dependency on a deferred spike. Task 2 Step 8 becomes a confirmation rather than a prerequisite. — Cost if wrong: a later Bevy bump changes glam and `animus-core` types stop unifying at the Bevy boundary; caught immediately by the first `animus-runtime` build.

**R3 (F3): Keep `image = "0.25"`.** — Probed `imageproc 0.27.0`; it depends on `image v0.25.10`. Single copy, no conflict. — Cost if wrong: two `image` copies and type mismatches in `silhouette`; caught at Task 10 compile time.

**R4 (F4): Keep `insta` declared but unused for now.** — Task 13's and 14's tests use plain assertions; the spec calls for snapshot tests later. An unused dev-dependency fails nothing. Deferred minor. — Cost if wrong: trivial.

**R5 (F5): Do NOT dispatch Tasks 2–5 to subagents in this run.** — Every M0 spike requires physical hardware or human visual judgement that no subagent can supply: T2 needs someone to see whether "TOP" renders at the top and whether the mesh vanishes when orbiting; T3 needs a 150% DPI display and eye-verified click accuracy; T4 needs OBS with the Spout2 plugin plus a phone camera filming two screens to measure latency; T5 needs a physically connected second display or projector. Executing Tasks 1 and 6–14 (the entire Bevy-free core — no GPU, no display, no Bevy) delivers a complete, independently tested unit. The spike binaries will be written as a separate follow-up and handed to the user to run. — Cost if wrong: the M1 plan waits on spike findings, which it already does by design; nothing in Tasks 1 and 6–14 depends on a spike outcome once R2 removed the glam dependency.

**R6 (F6, F7, F8): Carry the three interface gaps into the affected dispatches rather than amending the plan.** — `MeshPuppet::empty()` and `AssetStore::new()` belong to the tasks whose tests call them (T8, T13); `Default` on `SkeletonData` and `SolverConfig` belongs to T7; `signed_area` must be `pub` in `silhouette::topology` and re-exported from `silhouette` (T10). Each is a one-line addition, stated in its dispatch. — Cost if wrong: a compile error inside the task that owns it, caught by that task's own tests.

## cargo deny failure — controller investigation, for the final fix wave

`cargo deny check licenses advisories` **fails on the current tree**, so Task 1's `deny` CI job is red and the plan's Done Criteria are not met. The implementer correctly left it alone as out of scope and made no manifest changes. I traced all four errors:

| Error | Chain |
|---|---|
| `libfuzzer-sys` NCSA licence | ← `rav1e` ← `ravif` ← `image` **default features** |
| `paste` unmaintained | ← `pulp` ← `exr` ← `image` **default features** |
| `ttf-parser` unmaintained | ← `ab_glyph` ← `imageproc` **default features** (font rendering — we render no text) |
| `libbz2-rs-sys` bzip2 licence | ← `bzip2` ← `zip` |

The root cause is not four unrelated dependency problems. It is two:

1. **`imageproc` pulls `image` with default features**, which defeats our `default-features = false, features = ["png","jpeg"]` narrowing through feature unification, re-enabling the AVIF and OpenEXR codec stacks.
2. **`zip` is declared but entirely unused this milestone** — package export is a later milestone — and drags in bzip2.

**Verified fix, probed on a scratch crate:** setting `imageproc = { version = "0.27", default-features = false }` sheds `ravif`, `exr`, `rav1e`, `paste`, `libfuzzer-sys`, `ab_glyph`, `ttf-parser` and `rayon` outright — three of the four errors gone, dependency tree down to 58 nodes. `nalgebra` survives (still the source of the four glam versions flagged in Task 1's review). Dropping `zip`, or setting it `default-features = false`, clears the fourth.

**Ruling for the final fix wave: fix the dependency tree, do not weaken the licence allowlist.** Adding NCSA and bzip2 to `deny.toml` would make CI green while leaving a font renderer and two image codecs we never call in the build — and the spec names compile time as a standing risk.

That characterisation was wrong, and the deferred minor was wrong too. `cargo tree -p animus-core` contains `glam` exactly **once** (0.32.1); the other three versions appear only in `Cargo.lock`, as nalgebra's *optional and disabled* `convert-glam03x` features.
